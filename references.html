Research sources

References and useful links

The following seven resources were listed in the original Assignment #1 presentation. They include introductory explanations, technical documentation, and official project information.

  1. MDN Web Docs — Overview of HTTP
    https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview-of-HTTP
    Introduction to how HTTP works.
  2. MDN Web Docs — How the Web Works
    https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works
    Explains browsers, servers, and delivery of web resources.
  3. MDN Web Docs — What Is a Web Server?
    https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_web_server
    Overview of web server responsibilities.
  4. IETF RFC 9110 — HTTP Semantics
    https://www.rfc-editor.org/info/rfc9110/
    Technical specification for HTTP semantics.
  5. ICANN — The Domain Name System
    https://www.icann.org/resources/pages/dns-2022-09-13-en
    Explains the role of DNS on the Internet.
  6. Apache HTTP Server Project — About Apache
    https://httpd.apache.org/ABOUT_APACHE
    Background on the Apache HTTP Server project.
  7. NGINX — Celebrating 20 Years of NGINX
    https://blog.nginx.org/blog/celebrating-20-years-of-nginx
    History and development of NGINX.
