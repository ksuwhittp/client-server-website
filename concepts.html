Key Concepts

Seven terms that explain how client-server systems support the modern Web.

Quick reference

Seven essential concepts

These terms appear throughout client-server architecture and form the foundation of many web applications.

01

Client

A program or device that initiates a request. Browsers, mobile applications, and API clients are common examples.

02

Server

Software or infrastructure that processes requests and delivers data, websites, applications, or other services.

03

DNS (Domain Name System)

A system that helps clients find servers by associating domain names with IP addresses.

04

HTTP (Hypertext Transfer Protocol)

An application-layer protocol that defines how clients send requests and servers return responses.

05

HTTPS and TLS

HTTPS uses transport security, commonly TLS, to help encrypt data, authenticate servers, and protect messages in transit.

06

API (Application Programming Interface)

An interface that allows software programs to communicate using agreed rules; web APIs often use HTTP and JSON.

07

Load Balancing

A technique for distributing requests among servers to support performance, availability, and scaling.

How the concepts connect

A client uses DNS to locate a server, then communicates using HTTP or HTTPS. Some applications expose an API, while larger systems use load balancing to spread requests across multiple servers.
