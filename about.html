About This Project

This website was created for IT 3203 Project Milestone #1: Basic Website with HTML/CSS. It transforms my Assignment #1 research presentation into an informational website that is easy to navigate and read.

The purpose is to explain what clients and servers do, how web requests work, how different architectures are organized, and which technical concepts are important to understand.

Project focus: A six-page research website using semantic HTML, a single shared CSS stylesheet, navigation links, responsive page layouts, and original diagrams.

What I hope to learn

Through this project, I want to improve my HTML and CSS skills while gaining a stronger understanding of the systems that support modern websites. The project also provides a foundation for expanding the site in future milestones.
